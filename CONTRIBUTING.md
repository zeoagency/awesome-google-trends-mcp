# Contributing

Thanks for improving Awesome Google Trends MCP. This is a curated list — a good entry helps someone discover a high-quality Google Trends MCP server, scraper, client, or data pipeline.

**Read [AGENTS.md](./AGENTS.md) first** — it has the entry format, the sections, the verb-first style guidelines, and the inclusion bar. Everything you need to add a project is there.

## Pull request checklist

- [ ] I read [AGENTS.md](./AGENTS.md).
- [ ] The project is Google Trends-specific and publicly accessible on GitHub.
- [ ] The entry uses the standard format (`| [**owner/repo**](url) | <verb-first description> |`) and is placed in the right subcategory.
- [ ] The description is factual and specific — no hype, no filler, strictly $\le 3$ sentences.
- [ ] Links work and `npx markdownlint-cli2 "**/*.md"` passes with 0 issues.
